How to block Instagram & YouTube Shorts outside Moon (PC & iPhone)
  1. On PC Browser (Chrome / Edge / Brave): Tap "🧩 Enable Browser Blocker" above → open chrome://extensions → enable Developer mode → click Load unpacked and select the moon_antiscroll_extension folder. It automatically blocks YouTube Shorts (/shorts) and redirects Instagram Feeds to /direct/inbox/ (DMs & 1 Friend Reel only)!
  2. On iPhone (iOS Shortcuts Automation for Instagram + YouTube Apps):
    • Keep run_app.bat / serve.py running on your PC (same Wi-Fi).
    • In iPhone Shortcuts → Automation → + → App: select YouTube (Is Opened, Run Immediately):
      Action 1: Get Contents of URL /api/scroll
      Action 2: If result contains blocked → Go to Home Screen.
    • For Instagram (Is Opened, Run Immediately):
      Action 1: Get Contents of URL /api/scroll
      Action 2: If result contains dm_only → Open URLs instagram://direct-inbox (forces Instagram straight into your Chat Inbox, skipping Reels & Home!).
  3. Safari / Tampermonkey Userscript (iOS & PC): Install ig-noscroll.user.js to block YouTube Shorts & lock Instagram to DMs + 1 Friend Reel in Safari.
